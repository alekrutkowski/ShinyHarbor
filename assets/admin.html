Saved · restart required
The file has been saved, but the server is still using its current listeners and global settings. Restarting disconnects active apps, so choose a suitable moment.
  • Windows foreground: stop the current server, then use Start ShinyHarbor.
  • Windows service: in administrator PowerShell, Restart-Service ShinyHarbor.
  • Linux package: sudo systemctl restart shinyharbor.
  • macOS background service: use Stop background server, then Run at login.
  • Portable / terminal: Ctrl+C in the server terminal, then repeat your serve command.
If you changed a port, use its new address after restarting. The private dashboard and administration page use HTTP even when your app listener uses HTTPS.
